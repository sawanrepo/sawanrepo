### 📄 [Contract Review Bot](https://github.com/sawanrepo/Contract-review-bot)

An AI-powered contract analysis assistant for querying legal documents and identifying relevant clauses.

**Technologies:** Python, LangChain, LangGraph, FAISS, RAG, Streamlit
